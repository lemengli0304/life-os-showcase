# Life OS

**Real progress. A world that notices.**

Life OS is an independent browser-based prototype combining practical productivity tools with a persistent virtual town and eight state-driven NPCs. Created by Lea Li, a Computer Science student at University College London.

## Product
- User-defined tasks, focus sessions and eight dimensions of growth.
- Academy progression, in-world rewards and personalisation.
- Character routines, contextual authored dialogue and persistent relationships.

## Commercial thesis
A useful productivity core paired with optional cosmetic and story content. The next beta will test whether world attachment increases repeat real-world action. No revenue or retention claims are made.

## Project status
Working prototype in active development. This repository contains the public showcase only, not the full game or player saves. Implementation is AI-assisted; product direction, design and testing are independently led.

## Hosting
Self-contained static `index.html`; no build step or API keys required. Screenshots are embedded as optimised WebP images. GitHub Pages can serve the main branch root.
